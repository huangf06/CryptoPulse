# 题库答案查证工作流 Prompt

直接复制以下内容到新会话中使用。将 `Q{N}` 替换为要查证的题号。

---

## Prompt

```
深入查证 Q117 的权威答案。

工作流：
1. 用 PyMuPDF 从 `mock_exam/Certified Data Engineer Professional  327题.pdf` 提取题目全文（注意：代码块选项可能提取不出来，如果 C/D 等选项内容为空，渲染该页 PDF 为图片再读取）
2. 展示完整题目和所有选项
3. 派研究 agent 搜索网络：
   - ExamTopics 对应题号的讨论页（社区投票和争论）
   - GitHub 题库仓库（如 Amrit-Hub/Databricks-Certified-Data-Engineer-Professional-Questions）
   - Databricks 官方文档中与该题知识点直接相关的页面
   - 其他可信来源（CertLibrary、Medium 技术文章等）
4. 基于收集到的证据，独立做出技术判断：
   - 逐选项分析（每个选项为什么对或为什么错，引用具体技术事实）
   - 如果 PDF 答案与技术事实矛盾，明确指出 PDF 是错的
   - 如果社区共识与技术事实矛盾，跟着技术事实走，不跟着投票走
   - 如果题目本身措辞有问题，也要指出

关键原则：
- 不迎合 PDF 答案，不迎合社区共识——只跟着证据和技术事实走
- 每个选项的判断必须有具体技术依据，不能是"这个看起来对/不对"
- 如果发现该题在题库中有重复（如 Q94=Q200），一并指出并比较答案
- 最终给出明确结论：正确答案是什么，PDF 答案是否正确
```

## 批量查证（多题）

```
按照上述工作流，依次深入查证以下题目的权威答案：Q{A}, Q{B}, Q{C}

每题独立分析，逐题给出结论。如果多题之间有关联（重复题、同知识点），一并指出。
```
